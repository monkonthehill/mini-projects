# 🧠 Mini Projects in C++

Welcome to **Mini Projects in C++** — a growing collection of simple to biginner to intermediate C++ programs built to strengthen problem-solving, logic, and coding discipline.

👉 Repository: [https://github.com/monkonthehill/mini-projects](https://github.com/monkonthehill/mini-projects)

---

## 📂 Project List

| # | Project Name | File | Description | Key Concepts |
|---|---------------|------|-------------|---------------|
| 1 | **Guess The Number** | `GuessTheNumber.cpp` | A simple number guessing game where the user tries to guess a randomly generated number. | Loops, Conditionals, Randomization |
| 2 | **Rock Paper Scissors** | `Rock_paper_scissors.cpp` | Classic player vs computer game of rock, paper, scissors. | Conditionals, Random number, Game logic |
| 3 | **Cloverpit (Treasure Hunt)** | `cloverpit.cpp` | Mini text-based adventure game where the player hunts for treasure. | Loops, Functions, Game design logic |
| 4 | **TODO CLI App** | `todo.cpp` | Command-line To-Do app with add, list, and complete features. | File I/O, Structs, Vectors, Persistence |

## 🧩 Concepts Covered

- File handling (`ifstream`, `ofstream`)  
- STL containers (`vector`, `string`)  
- Modular functions  
- Conditional logic and loops  
- Random number generation  
- Data persistence for console tools
